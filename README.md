## 部署步骤

1. 打开 https://github.com/new ，新建一个 **Public** 仓库（例如 `two-tools`），不要勾选 README
2. 进入仓库 → **Add file → Upload files**
3. 把本文件夹里的所有内容（`index.html`、`jar.html`、`play.html`、`*.zip`、`img/`、`.nojekyll`）拖进去 → **Commit changes**
4. 仓库 → **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** / **（root）** → Save
5. 等 1–2 分钟，刷新 Settings → Pages，会出现网址 `https://<用户名>.github.io/<仓库名>/`
